# Early Work Archive (2018 – 2020)

Projects I built during my Bachelor of Engineering (Computer Science) at Chitkara
University, and in the months before my first engineering job.

They were originally published under my old GitHub account (`KaranGoel59`, later
`kgoel59`), which I deleted. The code here was recovered from
[Software Heritage](https://www.softwareheritage.org/), which had archived the public
repositories. Each folder is the **final archived state** of one original repository.

> **Archived, not maintained.** These are student projects from 2018–2020. The
> dependencies are years out of date and will have known vulnerabilities. Read them,
> don't deploy them. Config files (`.env`) and build output were left out on purpose.
